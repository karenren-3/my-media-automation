# Jiaojie 视觉系统

## 默认方向

把健康知识画成温暖、可信、易扫读的手绘信息图，而不是医疗广告或教科书解剖图。

- 画布：3:2 横图；建议 1536×1024 或其他等比例尺寸。
- 背景：带轻微纸张质感的暖米色，不使用纯白大底。
- 线条：炭黑色手绘线，略有自然起伏，但轮廓清晰。
- 色块：低饱和马卡龙色，扁平填充，允许少量铅笔或蜡笔颗粒。
- 文字：简体中文、短标签、手机端可读；正文不要塞进图片。
- 构图：一张图只解释一个主要问题，保留至少 8% 安全边距。
- 气质：清爽、温和、有力量；避免恐吓、羞辱身材或制造疾病焦虑。

## 固定色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 暖米色背景 | `#F7F0E4` | 全局底色 |
| 炭黑线条 | `#262421` | 轮廓与主文字 |
| 珊瑚粉 | `#E98B7B` | 重点、风险提醒 |
| 薄荷绿 | `#A9CDB8` | 可执行建议、恢复 |
| 天空蓝 | `#A9C6DE` | 解释、过程、睡眠 |
| 奶油黄 | `#E9CC78` | 提示、能量、营养 |
| 灰紫色 | `#B9ADD2` | 情绪、更年期、辅助层级 |

用户指定品牌色或其他色板时，以当前请求为准，但同一文章内保持一致。

## 中文层级

- 主标题：4–10 个汉字，单行优先。
- 分区标题：2–8 个汉字。
- 标签：2–8 个汉字；确有必要时最多 12 个。
- 一张图的独立文字块不超过 7 个。
- 需要解释的长句留在正文；图片只保留能帮助识别关系的词。
- 生成后逐字核对。错字、乱码或字形不清时，减少文字并重新生成新版本。

## 图型选择

| 图型 | 使用场景 | 构图重点 |
|---|---|---|
| 封面 | 文章核心冲突或主题入口 | 一个主体、一个短标题、留白充分 |
| 机制/流程 | 原因、变化链、恢复路径 | 3–5 个节点，箭头方向单一 |
| 对比 | 两种方法、误区与正确做法 | 左右或上下双栏，条件对称 |
| 框架 | 多因素、分类、决策结构 | 中心主题加 3–5 个分支 |
| 行动清单 | 读者可执行步骤、红旗信号 | 编号清楚，普通建议与警示分色 |

不要为了凑数量重复同一种信息。文章较短时选 3 张；结构较完整时选 4–5 张。用户明确指定数量时，重新分配信息，不机械复制画面。

## 检查清单

- 主旨是否一眼可懂？
- 中文是否逐字正确且足够大？
- 是否保持暖米色、手绘线与马卡龙色块？
- 人体动作是否自然，是否可能误导康复动作？
- 对比双方是否使用相同尺度和条件？
- 是否出现品牌标志、水印、角标或无关装饰？
- 画布是否为用户确认的比例？

任何一项失败，只重做该图。保留失败候选，使用 `-v2`、`-v3` 版本名，不覆盖旧文件。
