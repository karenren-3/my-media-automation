# 使用示例与触发条件

## 1. 显式调用：从 Word 生成完整发布包

```text
$jiaojie-health-illustrator 请读取 /path/to/article.docx，为这篇健康科普文章规划 3–5 张配图。先给我提纲确认，确认后生成 PNG、带图 Markdown、公众号可复制 HTML 和 ZIP。
```

## 2. 自然语言自动触发

```text
帮我给这篇更年期睡眠科普文章配公众号正文图，做成暖米色手绘信息图，并整理成可以直接复制到公众号的本地发布包。
```

## 3. 明确跳过确认

```text
$jiaojie-health-illustrator 按默认 Jiaojie 风格直接生成，不用确认。根据文章结构自动选择 3–5 张，完成本地公众号发布包，但不要登录或推送公众号。
```

“直接生成”只跳过出图前确认，不跳过健康风险扫描、提示词落盘、图片检查和发布包验证。

## 4. 覆盖风格、色板、比例和数量

```text
$jiaojie-health-illustrator 这篇康复文章只做 2 张 1:1 图片，改用冷灰蓝色板和极简编辑插画。先确认提纲；康复安全边界仍按加强级处理。
```

当前请求中的明确覆盖优先于默认 3–5 张、3:2 和马卡龙色板。验证时同步传入覆盖后的数量与比例。

## 5. 只生成配图

```text
$jiaojie-health-illustrator 为这篇营养科普只生成正文配图和已保存提示词，不需要改写文章、HTML 或 ZIP。先给我配图位置和画面方案。
```

此时报告必须说明这是局部交付，不称为完整公众号发布包。

## 6. 生成后上传微信公众号草稿箱

```text
$jiaojie-health-illustrator 为这篇健康科普生成完整发布包。验证通过后先让我确认，再上传到微信公众号草稿箱；不要群发。
```

上传是独立的可选阶段。必须先交付并验证本地发布包，再取得一次操作确认。向 `baoyu-post-to-wechat` 传递派生 Markdown，不传预转换 HTML。

作者或编辑者依次读取：本次请求、文章 frontmatter、所选公众号账户配置；都没有时留空。公开版本不得默认写入 Skill 作者或其他固定身份。

## 7. Claude Code 无位图后端时

```text
$jiaojie-health-illustrator 请在 Claude Code 中为这篇文章制作公众号配图和发布包。
```

先检查是否存在可用的 `baoyu-image-gen`、图像 MCP 或其他位图后端。没有后端时，只交付健康核查、`imgs/outline.md` 和 `imgs/prompts/*.md`，并明确说明 PNG、带图 HTML 和 ZIP 未生成。不得用 SVG、HTML 或程序化绘图冒充成品。

## 不会触发

- “把这篇科技新闻排成公众号 HTML”——非健康主题且只排版。
- “给活动做一张宣传海报”——单张营销海报。
- “把这张图改成短视频首帧”——视频画面任务。
- “只检查这篇文章有没有错别字”——纯编辑任务。

遇到以上任务，使用更匹配的排版、海报、视频或编辑 Skill。
